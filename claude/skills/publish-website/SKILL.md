# publish-website

Publishes content to jagadeshbabu.com via Hugo. Handles creating new essay
files, updating existing pages, building, and deploying via git push.

**Hugo project:** `~/Workspace/website/`
**Live site:** jagadeshbabu.com
**Deploy:** git push → Cloudflare Pages auto-builds (via GitHub app)

> **IMPORTANT:** Never run `git push` without explicit approval from Jagadesh. Stage and commit, then show the commit and ask before pushing.

| Request | Action |

## File: New Essay

### Step 1 — Determine the slug

Derive from the title. Rules:
- Lowercase, hyphens only, no special characters, max 50 chars
- "Clarity is manufactured" → `clarity-is-manufactured`
- "Why DevEx is a product problem" → `devex-is-a-product-problem`

### Step 2 — Create the file

```bash
cd ~/Workspace/website
hugo new writing/[slug].md
```

Or write directly:

```bash
cat > ~/Workspace/website/content/writing/[slug].md << 'MDEOF'
---
title: "[Full title]"
date: [YYYY-MM-DD]
draft: false
description: "[1–2 sentence summary for post list and meta tags.]"
pillar: "[org-culture | platform-infra | leadership]"
tags: ["tag1", "tag2", "tag3"]
---

[Essay body in pure markdown]
MDEOF
```

### Step 3 — Verify locally (optional)

```bash
cd ~/Workspace/website
hugo server
# Open http://localhost:1313/writing/[slug]/
```

### Step 4 — Stage and commit (then ask before pushing)

```bash
cd ~/Workspace/website
git add content/writing/[slug].md
git commit -m "post: [title]"
```

Then show the commit to Jagadesh and ask: "Ready to push to GitHub and trigger the Cloudflare Pages deploy?"

Only run `git push origin main` after explicit approval.

## Git Deploy Reference

```bash
# Stage a single file
git add content/writing/[slug].md

# Stage all changes
git add -A

# Commit
git commit -m "post: [title]"
# or
git commit -m "update: now page March 2026"
# or
git commit -m "edit: [slug] — [what changed]"

# Push and trigger Cloudflare Pages build
git push origin main

# Check deploy status
# → dash.cloudflare.com → Pages → your project → Deployments
```

## Full Publish Flow

When Jagadesh says "publish [essay content]", execute this sequence:

```bash
# 1. Write the file
cat > ~/Workspace/website/content/writing/[slug].md << 'MDEOF'
[front matter + essay body]
MDEOF

# 2. Verify locally (optional)
cd ~/Workspace/website && hugo --buildFuture server

# 3. Stage and commit
git add content/writing/[slug].md
git commit -m "post: [title]"
```

Then confirm with Jagadesh: "Committed. Ready to push to GitHub and trigger the Cloudflare Pages deploy?"

```bash
# 4. Push only after explicit approval
git push origin main
```

Live at: `https://jagadeshbabu.com/writing/[slug]/` (after Cloudflare Pages deploys, ~60s)

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Post not showing | Check `draft: false` in front matter |
| Post missing after deploy | Post date may be "future" in UTC — Cloudflare Pages does NOT read `netlify.toml`. Build command must be set to `hugo --buildFuture` in the Cloudflare Pages dashboard: Pages → project → Settings → Builds & deployments → Build command |
| Build error | Run `hugo` and read the error message |
| Port 1313 busy | `hugo server -p 1314` |
| Git push rejected | `git pull origin main` first, then push |
| Cloudflare Pages not deploying | Check dash.cloudflare.com → Pages → your project → Deployments |
| CSS not loading | Verify `static/css/main.css` exists |
| Page 404 | Check filename matches the slug in URL |
